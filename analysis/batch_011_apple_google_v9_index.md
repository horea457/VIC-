# 2. Batch 011의 핵심 질문

이 배치의 공통 질문은:

> **현재 관측되는 제품·margin·valuation이 미래 terminal economics를 얼마나 설명하는가?**

Apple과 Google 모두 현재 본업에서 이미 큰 현금흐름을 만들면서 동시에:
- 설치기반
- distribution
- 개발자 / 광고주 생태계
- 데이터
- 자체 R&D

를 통해 미래 option을 계속 만들었다.

따라서 좋은 Long은 대개:

**현재 core value로 하방을 만들고  
미래 option에 낮은 가격을 지불**

하는 구조였다.

반대로 실패한 Short는 대개:

**현재 높은 margin / valuation  
→ 평균회귀  
→ 주가하락**

을 너무 직접적으로 연결했다.

# 3. Apple — Hardware가 아니라 Installed Base 경제성

Apple을 iPhone unit과 gross margin으로만 보면 장기 economics를 놓친다.

핵심은:

**Hardware gross profit  
+ Installed base × Services ARPU  
- ecosystem reinvestment  
= operating cash flow**

그리고 큰 buyback을 반영하면:

**Company FCF  
÷ diluted share count**

가 실제 주주에게 더 중요하다.

## 2001 / 2003 Long이 강했던 이유

이 두 아이디어의 핵심은 미래 iPhone을 맞힌 것이 아니다.

당시 가격이:
- 많은 순현금
- 낮은 영업사업 가치

로 하방이 제한되어 있었고, 새 제품이 성공할 경우 upside는 컸다.

즉:

> **미래 innovation을 예측한 것이 아니라 거의 공짜로 샀다.**

실제 초과수익 대부분은 원문이 충분히 예측하지 못한:
- iPod
- iTunes
- iPhone
- Services

에서 나왔다.

이것은 **인과 일부 오류가 있어도 payoff 구조가 매우 좋았던 사례**다.

# 4. Apple 2011 / 2013 / 2017 Long — 제품이 아니라 생태계와 주당가치

2011에는 iPhone·iPad unit growth가 중요했지만 장기적으로 더 강한 자산은:

- iOS
- App Store
- iMessage
- developer ecosystem
- accessories
- 자체칩
- 브랜드
- privacy positioning

의 결합이었다.

2013에는 margin peak 우려가 컸지만:
- 큰 cash balance
- capital return
- buyback

이 주당가치를 지지했다.

2017에는 iPhone unit growth 둔화가 있었지만 설치기반 위에서 Services가 커졌다.

### 재사용 식

**Installed base growth  
× Services ARPU growth  
+ hardware gross profit growth  
+ buyback accretion  
= per-share value growth**

# 5. Apple Shorts — 왜 모두 실패했나

## 2017 Short
Short는 스마트폰 profit pool이 경쟁으로 평균회귀할 것으로 봤다.

이론적으로 합리적인 질문이었다.

하지만 Apple의 moat를:
- hardware differentiation

중심으로 보고,
- OS
- ecosystem
- Services
- switching cost
- buyback

을 충분히 반영하지 않았다.

결과적으로 약 $30 → $184.40으로 가며 Short 가격손실은 약 **-515%**.

## 2021 Short
34배 이익과 App Store 규제 우려를 근거로 했다.

하지만 **비싸다**는 것과 **투자기간 안에 하락한다**는 것은 다르다.

Short가 성공하려면 적어도 하나가 필요했다.

1. earnings revision down
2. multiple compression
3. 규제가 실제 profit pool을 훼손
4. buyback 둔화

그런데 earnings denominator가 계속 성장했다.

결과적으로 약 $125 → $184.40, Short 가격손실 약 **-47%**.

### 핵심 원칙

> **Valuation-only Short는 catalyst 없는 경우 carry가 매우 불리하다.**

# 6. Google — Search core와 Distribution

Google의 본업은 검색 intent를 monetization하는 것이다.

핵심식은:

**Search / YouTube revenue  
- TAC  
- infra / capex  
- R&D / sales  
= core FCF**

여기서 가장 중요한 구조적 자산은:
- 검색 품질
- query habit
- browser / mobile distribution
- 광고주 ROI

다.

## 2009 Long
금융위기 후 광고경기 우려 속에서:
- search core
- 순현금
- 높은 FCF

로 하방을 만들고 YouTube·Android를 큰 값을 지불하지 않고 보유했다.

실제 약 $8.36 → $141.80, 약 **+1,596%**.

## 2012 Long
약 12.5x EBIT에서 search moat를 샀다.

높은 성장주가 아니라 이미 매우 수익성 높은 core business를 낮은 valuation에 산 구조였다.

## 2015 Long
Search core를 낮게 평가하면서:
- YouTube
- Cloud

를 option으로 분리했다.

이 역시 좋은 구조였다.

---

# 7. Google에서 추가로 봐야 할 위험

Search moat가 강해도 distribution이 공짜는 아니다.

특히 TAC는:
- Apple default search
- browser agreements
- mobile distribution

비용이다.

규제로 default distribution이 훼손되면:
- TAC economics
- query share
- monetization

이 같이 움직일 수 있다.

따라서 앞으로는:

**Search moat  
× distribution access probability  
- TAC  
- regulatory remedy cost**

를 같이 봐야 한다.

AI search도 같은 프레임이다.

핵심은 단순 query share가 아니라:

**AI answer mix  
→ commercial query density  
→ ad load / conversion  
→ cost per query**

까지 이어지는지다.

# 10. Batch 011에서 추출되는 V9 원칙

### 원칙 1
**Current economics ≠ Terminal economics**

혁신기업에서는 특히 중요하다.

### 원칙 2
**좋은 option 투자는 미래를 정확히 맞힐 필요가 없다**

현재 core로 하방을 만들고 option에 과지불하지 않으면 된다.

### 원칙 3
**Installed base와 distribution은 회계장부에 잘 안 잡히는 자산이다**

하지만 장기 moat와 monetization을 결정한다.

### 원칙 4
**ROIC를 제품단위로만 보지 않는다**

ecosystem R&D, Services, buyback까지 포함해 per-share value creation을 본다.

### 원칙 5
**비싸다는 사실만으로 Short하지 않는다**

명확한 earnings/catalyst path가 필요하다.

### 원칙 6
**규제는 binary probability 하나가 아니다**

growth, distribution, margin, terminal multiple을 동시에 바꿀 수 있다.

### 원칙 7
**성공 원인이 원 논지와 달라도 구분해서 기록한다**

Apple 2001/2003처럼 미래 신사업을 못 맞혀도 entry structure가 탁월했다면 투자결과와 분석정확도를 별도로 평가한다.
