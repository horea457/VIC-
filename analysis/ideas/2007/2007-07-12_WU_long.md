# 1. 사업의 경제 엔진

WU의 송금 원금은 매출이 아니다.

**Transaction volume × (fee + FX spread)  
- agent commission  
- compliance/fraud cost  
- technology/marketing  
= operating profit**

따라서 transaction이 늘어도:
- 평균 fee 하락
- FX spread 축소
- agent economics 악화
- compliance 비용 상승

이 더 빠르면 이익은 늘지 않을 수 있다.

Agent network는 WU가 직접 점포를 소유하지 않고도 광범위한 현금 입출금망을 제공하게 해 asset-light 특성을 만든다. 하지만 **network가 존재한다는 사실과 그 network에서 경제적 지대를 유지한다는 사실은 다르다.**

# 2. 원문 Claim

## C1. Agent network가 점유율을 높인다
원문은 약 305,000개 agent와 브랜드가 양면 network effect를 만든다고 봤다.

**사전 반증조건:** agent 수와 transaction은 늘지만 revenue/transaction 또는 margin이 하락.

**실제:** network는 유지됐지만 operating margin은 대략 2005년 32% → 2006년 29% → 2007년 26%로 하락했다.

**판정: 부분 적중**

Network durability는 맞았지만 pricing power를 과대평가했다.

## C2. Remittance·점유율 성장으로 이익이 10% 복리한다
이민과 국경간 송금시장 성장, 점유율 10%→15%를 가정해 10년간 약 10% earnings growth를 기대했다.

**실제:** 2007 revenue는 약 +9%였지만 operating income은 약 +1%에 그쳤다.

즉:
**Volume growth ≠ Profit growth**

였다.

**판정: 실패**

## C3. Asset-light FCF로 $3.5bn 스핀부채를 빠르게 상환
연 약 $500m debt reduction이 가능하다고 봤다.

현금창출력 자체는 존재했지만 debt service는:
- buyback
- dividend
- acquisition
- investment

와 자본을 경쟁했다.

**판정: 부분 적중**

생존능력과 equity compounding을 혼동했다.

## C4. DCF $32
10년 10%, 이후 5년 6% 성장 가정으로 약 $32를 제시했다.

이 DCF의 가장 취약한 부분은 성장률보다 **margin bridge**였다.

가격과 비용 압박을 넣지 않은 거래량 성장 DCF였다.

**판정: 실패**

# 4. 무엇이 틀렸나

원문은:
**송금시장 성장 → 거래량 증가 → WU 이익 증가**

를 거의 직선으로 연결했다.

실제 bridge는:

**시장 성장  
→ WU transaction  
→ price/mix  
→ agent commission  
→ compliance  
→ operating margin  
→ FCF/share**

였다.

이 중 중간 단계가 빠졌다.

# 5. 재사용 가능한 교훈

1. **Network effect와 pricing power는 분리한다.**
2. **Volume KPI가 늘어도 revenue/transaction과 margin을 반드시 같이 본다.**
3. **Asset-light는 leverage risk가 없다는 뜻이 아니다.**
4. **DCF는 volume growth가 아니라 주당 FCF driver로 만든다.**
5. **첫 반증은 EPS가 아니라 revenue growth와 op-income growth의 divergence에서 나타날 수 있다.**

## 최종 한 문장

> **거래량이 늘고 network가 유지되는 것만으로는 좋은 compounder가 아니다. 경제적 지대가 거래당 얼마나 남는지가 핵심이다.**
