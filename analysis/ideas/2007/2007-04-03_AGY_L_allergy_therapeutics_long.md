## 4. 핵심 오류

원문은 base business와 pipeline을 SOTP로 분리했지만 **pipeline 실패 시 base business가 R&D financing burden까지 떠안는 구조**를 충분히 반영하지 못했다.

즉:

**Equity floor ≠ base-business standalone value**

이고,

**Equity floor = base-business value - pipeline burn - financing/dilution cost**

로 봐야 했다.

---

## 5. 재사용 가능한 교훈

1. biotech/pharma SOTP에서 pipeline burn을 base business에서 차감한다.
2. efficacy와 regulatory approvability는 별개다.
3. adverse-event hold는 probability뿐 아니라 time-to-market을 크게 바꾼다.
4. “core business가 downside를 지지”한다면 core cash flow가 R&D burn을 감당할 수 있는지 본다.
5. partnership catalyst는 regulatory status가 선행조건이다.
