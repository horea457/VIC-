# 1. 사업구조 — Mastercard는 신용위험보다 network economics가 핵심이다

Mastercard는 카드대출을 직접 많이 보유하는 은행이 아니라 결제 network에 가깝다.

핵심 경제식은:

**Gross dollar volume / switched transactions  
× network / processing economics  
- customer incentives  
- operating cost  
= network operating profit**

따라서 가맹점이 내는 전체 interchange를 Mastercard 매출로 보면 안 된다. 대부분의 신용위험은 발급은행이 부담한다.

핵심 KPI는:
- GDV
- switched transactions
- cross-border volume
- incentives
- net revenue per transaction
- operating margin
이다.

좋은 network는 거래량 증가가 고정비 위에 얹혀 높은 incremental margin을 만들 수 있다.

# 2. 원문 투자논지

주가 $200에서 2011년 EPS $16.27의 12.3배, 순현금 제외 약 10배에 불과하다고 봤다. 944m장 카드·30.6m 가맹점·210개국을 연결하는 승인·청산·결제망은 분당 42,637건을 처리해도 건당 네트워크 비용이 약 2센트라 추가 거래의 margin이 높았다. 현금·수표에서 전자결제로 이동하는 구조적 성장, 유럽 SEPA debit 전환과 고정비 레버리지를 결합해 2012 EPS $19.31, 18개월 목표 $330을 제시했다. Durbin은 발급은행 interchange를 제한하지 Mastercard의 assessment·processing 수익을 직접 가격규제하는 것은 아니며 미국 debit은 매출 약 10%라고 분리했다.

## 당시 가장 중요한 insight

세계 GDV와 switched transactions가 장기 복리 성장했다.

# 8. V9 Postmortem

결제주는 다음 bridge로 본다.

1. **Volume:** TPV / GPV / GDV가 실제로 성장하는가.
2. **Mix:** branded / unbranded, domestic / cross-border, merchant mix가 어떻게 바뀌는가.
3. **Take-rate quality:** incentive·partner payment·network fee를 뺀 net economics가 유지되는가.
4. **Margin:** gross profit 성장보다 transaction / contribution margin이 중요한가.
5. **SBC / dilution:** 기업 성장률이 주당가치 성장률로 남는가.
6. **M&A:** 매출성장 유지가 아니라 주당 FCF accretion이 있는가.
7. **Valuation:** 같은 20% 성장도 12x와 35x는 전혀 다른 투자다.
8. **Short:** 단순 고평가가 아니라 어떤 operating metric이 깨져야 하는지 사전 정의한다.

# 9. 재사용 가능한 교훈

1. 전자결제 전환 가설에는 ‘결제량 성장 둔화가 3년 지속’를 사전 반증조건으로 저장한다.
2. 고정비 네트워크 가설에는 ‘고객 incentive가 매출 증가를 모두 흡수’를 사전 반증조건으로 저장한다.
3. Durbin 분리 가설에는 ‘미국 debit volume·routing 상실이 전사이익을 크게 훼손’를 사전 반증조건으로 저장한다.
4. 싼 진입 가설에는 ‘소송·규제로 정상 EPS가 영구 하락’를 사전 반증조건으로 저장한다.
5. 주당가치 귀속 가설에는 ‘사업 지표는 늘지만 완전희석 주당 잉여현금흐름이 정체하거나 감소’를 사전 반증조건으로 저장한다.
6. 촉매와 보유경로 가설에는 ‘목표가가 최종적으로 맞더라도 중간 손실 또는 논지 반증이 포지션을 파괴’를 사전 반증조건으로 저장한다.

### 한 문장 결론

> 규제 대상을 issuer interchange와 network fee로 분리했고, 높은 ROIC를 회계상 margin이 아니라 네트워크의 낮은 증분비용과 연결했다. 단기 SEPA 수치보다 장기 cash-to-card 전환과 양면망의 가격력이 실제 성공의 주원인이었다.
