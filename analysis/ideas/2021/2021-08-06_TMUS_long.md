# 1. 사업과 돈의 흐름

T-Mobile US는 전국 무선망에 가입자를 얹는 고정비 통신사업자다. spectrum·radio network에 선투자한 뒤 추가 가입자의 증분비용이 상대적으로 작아 share gain과 churn 개선이 operating leverage로 연결될 수 있다.

주주가치 bridge는:

**Gross adds × conversion  
- churn  
= net adds  
→ service revenue / ARPA  
→ fixed-cost absorption  
→ EBITDA  
- sustaining / integration CapEx  
= FCF  
→ debt reduction / buyback  
= FCF/share**

Sprint 이후에는 2.5GHz mid-band spectrum과 중복망 철거가 핵심이었다. 따라서 단순 EV/EBITDA보다 **고객 share gain → network efficiency → synergy cash → FCF/share**가 실제로 이어지는지 확인한다.

# 2. 원문 투자논지 — 당시 숫자로 재구성

## 당시 핵심 insight

# 7. Causal Postmortem

## 실제 성공의 인과사슬

**Un-carrier / network 개선  
→ gross adds 상승·churn 하락  
→ net adds와 service revenue share gain  
→ fixed-cost absorption  
→ EBITDA·FCF 증가  
→ spectrum deployment / Sprint synergy가 capacity를 추가 확대  
→ integration 종료 후 FCF 급증  
→ buyback이 FCF/share 증가를 가속**

즉 자사주는 원인이 아니라 **이미 개선된 고객·network economics가 만든 잉여현금의 결과**였다.

## 무엇을 맞혔나

spectrum, customer cohorts, rural/enterprise TAM, FWA, synergy와 buyback을 하나의 FCF/share 모델로 연결한 프로세스가 강하다. 장기 buyback 가격 가정은 path-dependent하다.

## Root error / 남은 약점

사업·spectrum·synergy를 FCF/share로 연결하면서 path-dependent 가정을 별도 관리

# 9. Counterfactual — 더 나은 분석이었다면

**더 나은 투자판정 규칙:** M&A나 multiple expansion 없이도 standalone FCF/share가 목표수익률을 만드는지 먼저 확인한다. Sprint 같은 옵션은 별도 확률가중하고, 실제 synergy가 확인된 뒤에만 FCF/share 추정을 올린다.
