# 1. HBO Max 성장과 AT&T 주식가치는 같은가

이 Long은 HBO Max subscriber surprise를 중요한 rerating catalyst로 봤다.

하지만 parent equity value는:

**Connectivity value  
+ WarnerMedia value  
+ other assets  
- net debt  
- corporate discount**

다.

WarnerMedia가 잘돼도 그 자산이 계속 AT&T common 안에 남아 있어야 원래 SOTP가 유지된다.

# 2. 원문 논지
AT&T가 약 10x earnings와 높은 dividend yield에 거래돼 매우 싸며, 시장이 HBO Max subscriber trajectory를 크게 과소평가한다고 봤다. 약 3년 내 global 50m incremental subscribers가 $14.99/month로 추가되면 약 $0.76 EPS를 만들 수 있다고 단순 계산했고, 2021-01-27 실적발표에서 HBO Max subscriber beat가 valuation catalyst가 될 것이라 주장했다.

핵심 insight: 통신 FCF가 좋아도 M&A·spin·debt가 기존 보통주에 귀속되는 방식을 바꾼다. segment operating success와 parent-company payoff를 분리한다.

# 3. 당시 시장 기대

시장은:
- HBO Max 초기 subscriber traction
- wireless/fiber FCF
- 높은 debt
- DirecTV decline
- 미디어 conglomerate discount
를 함께 가격에 반영했다.

Long은 HBO Max가 예상보다 잘되면 미디어 가치가 크게 재평가될 것으로 봤다.

# 4. Causal chain

**HBO Max subscriber surprise  
→ WarnerMedia growth expectations 상승  
→ segment value 상승  
→ AT&T SOTP 상승  
→ parent multiple rerating**

실제 chain은 앞부분은 맞았지만, **WarnerMedia 분리**로 parent claim 구조가 바뀌었다.

# 8. 실제 성과

운영촉매는 강하게 적중했다. 2020말 domestic HBO Max/HBO는 41m+로 초기 계획을 2년 앞섰고, 2021년 3월 회사는 2025 global HBO Max/HBO 목표를 75~90m에서 120~150m으로 상향했다. 2021말 글로벌 HBO Max/HBO는 73.8m이었다. 그러나 2021년 5월 AT&T는 WarnerMedia를 Discovery와 결합해 분리하기로 발표했다. 따라서 HBO Max 성공이 AT&T 내 multiple rerating으로 연결된다는 핵심 security bridge가 끊겼다.

HBO Max subscriber thesis는 빠르게 적중했지만 AT&T는 2021-05 WarnerMedia 분리를 발표했다.

2024-01-31 기준 package value는 대략:
- AT&T $15.85
- 배분된 0.241917 WBD × $10.02 ≈ $2.42
- 합계 약 **$18.27 before dividends**

로 원 entry와 $51~63.5 target을 크게 하회했다.

즉 **segment operating thesis 성공 / parent security thesis 실패**다.

# 10. 최초 thesis break

- 2021-05-17 — AT&T가 WarnerMedia/Discovery 거래를 발표하면서 HBO Max가 AT&T valuation을 직접 끌어올린다는 thesis가 4개월 만에 구조적으로 무효화됐다.

기업구조 변경 발표는 단순 뉴스가 아니라 valuation identity 자체를 바꾸는 thesis break다.

# 11. Corporate action bridge

Spin / split / asset sale이 있으면:

**Pre-event equity value  
→ retained parent value  
+ distributed security value  
- transaction leakage / debt transfer / tax**

로 다시 계산해야 한다.

기존 SOTP target을 그대로 유지하면 안 된다.

# 12. Counterfactual

$51~63.5 thesis가 맞으려면:
1. HBO Max 성장
2. WarnerMedia가 parent 안에 유지
3. media multiple rerating
4. net debt 감소
5. DirecTV drag 완화
가 동시에 필요했다.

# 13. 재사용 규칙

1. Segment success와 parent equity payoff를 분리한다.
2. Corporate action은 thesis identity를 바꿀 수 있다.
3. Spin 발표 즉시 SOTP를 새 청구권 기준으로 다시 만든다.
4. 성장자산이 분리되면 parent multiple과 FCF profile도 새로 계산한다.
5. 분배받은 주식까지 포함해 package return을 계산한다.
6. 배당과 spin value를 누락한 단순 price chart는 사용하지 않는다.
