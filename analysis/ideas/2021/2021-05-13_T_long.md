# 1. 이 아이디어의 핵심 — SOTP와 청구권

원문은 WarnerMedia에 높은 가치를 부여하고 wireless/fiber core와 합산해 약 $65 SOTP를 제시했다.

하지만 SOTP는 단순 segment 합계가 아니다.

**Segment value  
× parent shareholder capture probability  
- net debt  
- transaction leakage  
- conglomerate / capital-allocation discount  
= parent equity value**

가 필요하다.

# 2. 원문 논지

AT&T의 핵심 upside를 세 축으로 봤다. 첫째 WarnerMedia가 HBO Max D2C로 Netflix/Disney 다음 글로벌 player가 되어 수익·valuation 비중을 크게 늘린다. 둘째 T-Mobile이 wireless leader가 되어도 3강 구조로 competition은 과거보다 완화되고 AT&T wireless ROIC 9.5%가 7%로 떨어질 필요가 없다. 셋째 fiber는 10~15% ROIC로 15m homes에서 35m homes까지 확장 가능하다. Jason Kilar와 개선된 management가 과거 DirecTV 실수를 되돌린다고 봤다.

핵심 insight: 통신 FCF가 좋아도 M&A·spin·debt가 기존 보통주에 귀속되는 방식을 바꾼다. segment operating success와 parent-company payoff를 분리한다.

# 3. 당시 시장 기대

시장은:
- WarnerMedia/HBO Max 성장
- wireless/fiber 안정
- DirecTV decline
- leverage
- conglomerate discount
를 동시에 보고 있었다.

Long은 WarnerMedia를 시장이 너무 싸게 평가한다고 봤다.

# 4. 가장 큰 숨은 가정

> **WarnerMedia의 가치가 AT&T common 안에서 계속 같은 방식으로 귀속된다.**

그런데 불과 4일 뒤 이 가정이 깨졌다.

# 8. 실제 성과

가장 중요한 반증이 매우 빨랐다. 2021년 5월 17일, 글 게시 4일 뒤 AT&T는 WarnerMedia를 Discovery와 결합해 분리한다고 발표했다. 따라서 Warner가 AT&T profit 35%·valuation 55%가 된다는 핵심 corporate-structure 전제는 즉시 사라졌다. 거래는 2022년 4월 8일 완료됐고 AT&T 주주는 1주당 0.241917 WBD를 받았다. 다만 운영조각 중 fiber는 실제로 강했다. 2021 AT&T는 fiber subscribers 약 1m 순증했고 이후 fiber build를 계속 확대했다. HBO/HBO Max도 2021말 73.8m까지 성장했다.

불과 **4일 뒤 WarnerMedia 분리 발표**로 핵심 SOTP 구조가 사실상 무효화됐다.

2024-01 package value는:
- AT&T $15.85
- 0.241917 WBD × $10.02 ≈ $2.42
- 합계 약 **$18.27 before dividends**

로 entry 대비 크게 낮았다.

# 9. 왜 이것이 강한 thesis break인가

일반적인 earnings miss가 아니다.

기업구조 변경은:
- 어떤 자산을 보유하는지
- 부채가 어디에 남는지
- dividend policy
- multiple
을 모두 바꾼다.

즉 **valuation model의 identity 자체가 바뀐다.**

# 10. 4일 만에 반증된 논지에서 배울 것

이 사례는 hindsight 문제가 아니다.

Corporate action 발표 시점부터는 누구나:
- WarnerMedia가 분리됨
- AT&T parent가 connectivity 중심으로 바뀜
- 기존 SOTP target을 그대로 쓸 수 없음

을 알 수 있었다.

따라서 첫 thesis break가 매우 명확하다.

# 11. Re-underwrite framework

분리 발표 즉시:

**RemainCo AT&T FCF / share  
+ distributed WBD value  
+ dividends  
- transferred / retained debt effects**

로 새로 계산했어야 한다.

기존 $65 target은 폐기 대상이다.

# 12. Counterfactual

원 SOTP가 맞으려면:
1. WarnerMedia parent 내 유지
2. HBO Max 성장
3. media multiple rerating
4. wireless/fiber FCF 안정
5. debt 감소
6. conglomerate discount 축소
가 필요했다.

첫 번째 조건부터 4일 만에 깨졌다.

# 13. 재사용 규칙

1. SOTP에는 shareholder capture probability를 넣는다.
2. Corporate action은 즉시 새 security map을 만든다.
3. 4일 만에 구조가 바뀌면 목표가가 아니라 thesis 자체를 폐기/재작성한다.
4. Spin-off는 parent와 distributed security를 합산해 total return을 계산한다.
5. Segment value가 맞아도 parent security가 실패할 수 있다.
6. 좋은 자산의 존재와 그 자산의 주주귀속은 별도 문제다.
