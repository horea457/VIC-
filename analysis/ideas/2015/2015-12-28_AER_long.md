# 1. 사업구조 — 항공기 자산가치와 equity value는 다르다

AerCap은 항공기를 매입해 항공사에 장기 임대하고 lease rent를 받는 항공기 lessor다.

핵심 경제식은:

**Lease rent  
+ aircraft sale gains  
- interest  
- depreciation / impairment  
- SG&A / credit loss  
= equity earnings**

하지만 leverage가 높아 실제 equity는 자산가치 변화에 확대 노출된다.

예를 들어 자산 100, 부채 70, equity 30에서 자산가치가 10% 하락해 90이 되면 equity는 20으로 약 33% 줄어든다.

따라서 P/B보다:

**Stress aircraft value  
- net debt  
- required liquidity reserve  
= stress equity value**

를 봐야 한다.
