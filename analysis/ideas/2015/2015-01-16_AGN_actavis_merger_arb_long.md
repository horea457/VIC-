## 5. Arb Return 해석

merger-arb return은 단순 AGN price return이 아니다.

**Gross arb P&L = target consideration - AGN purchase cost - hedge P&L adjustments**

따라서 exact annualized IRR은 실제 hedge fills 없이 계산하지 않는다.

---

## 6. 재사용 가능한 교훈

1. merger arb는 target fundamental value와 별개다.
2. mixed cash/stock deal은 exchange ratio만큼 acquirer hedge를 둔다.
3. spread보다 break probability와 time-to-close가 중요하다.
4. exact IRR은 hedge execution 없이 만들지 않는다.
5. closing terms와 실제 consideration을 primary source로 검증한다.
