# 1. 사업구조 — ULCC operating model과 security payoff를 분리한다

Spirit는 낮은 base fare에 ancillary fee를 붙이고, 높은 좌석밀도와 aircraft utilization로 CASM을 낮추는 ULCC다.

핵심 경제식은:

**Passenger revenue + ancillary revenue  
- fuel  
- labor  
- airport / maintenance  
- aircraft lease / ownership cost  
= airline operating profit**

하지만 같은 회사라도 common, EETC, merger-arb는 완전히 다른 투자다.

**EETC**는 특정 항공기를 담보로 하는 구조화 채권으로, 항공사 common보다 담보·priority가 앞선다.

**Merger arb**는 사업가치가 아니라:

**closing probability × deal value  
+ break probability × standalone value**

로 계산해야 한다.
