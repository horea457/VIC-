# 1. 당시 사업

Advanta는 여러 자산이 섞인 복잡한 금융회사였다.

- small-business credit cards
- leasing runoff
- small venture portfolio
- Fleet / JPMorgan-Chase 관련 litigation claims
- 각종 securitization / receivables

당시 시장은:
- leasing residual losses
- charge-offs
- securitization opacity
- management credibility
- litigation uncertainty

때문에 book value 자체를 신뢰하지 않았다.

# 2. 원문 투자논지

### A. Price far below book
Book ~$14.10 대비 B shares 약 53% 수준.

writer는 reported book보다 실질 book을 약 **$10**으로 더 보수적으로 봐도 저평가라고 판단했다.

### B. Core business-card earnings
business card operation은 약:
- current EPS $1.40
- next year $1.60~1.70

potential을 가졌다고 봄.

실질 book $10에:
- 15% ROE → $1.50 EPS
- 10% ROE → $1.00 EPS

이라면 $7.5 가격은 낮다는 논리.

### C. Leasing runoff releases capital
문제가 된 leasing portfolio가 줄면서 손실·필요자본도 줄고 capital이 core card business로 이동 가능.

### D. Litigation optionality
Fleet reserve 약 $70m에 대해 writer는 $70~100m award 가능성을 기대했고 Chase litigation은 downside가 제한적이라고 봤다.

# 3. 실제 경로

Advanta의 주가는 GFC 전 수년간 크게 상승했다.

공식 stock-performance table에서도 Class B는 2004~2007 동안 몇 배 상승한 뒤 2008 급락한다.

즉:
**cheap book + improving core ROE + credit expansion**
은 상당기간 매우 강한 payoff를 만들었다.

하지만 2008~09:
- small-business credit losses 급증
- funding stress
- card receivables deterioration
- industrial-bank/brokered-funding dependence

가 동시에 악화됐다.

2009-11 Advanta는 Chapter 11을 신청했고 common equity는 liquidation 과정에서 사실상 wipeout됐다.

# 5. 가장 중요한 사후교훈

이 사례는 결과기간을 어떻게 잡느냐에 따라 성공/실패가 완전히 달라진다.

- 1~5년 value rerating 투자: **매우 성공 가능**
- 영구보유 quality franchise: **실패**

따라서 금융주는 현재 book discount만 볼 것이 아니라:
**그 book을 만드는 credit underwriting과 funding structure가 cycle에서 살아남는지**를 봐야 한다.

특히 ROE가 높아질수록:
- leverage
- underwriting looseness
- wholesale funding
- reserve assumptions

중 무엇이 기여했는지 분해해야 한다.

### 한 문장 교훈
> **싸고 높은 ROE의 금융주는 몇 년간 엄청난 value trade가 될 수 있지만, 그 ROE가 tail-risk를 축적한 결과라면 book value는 안전마진이 아니라 지연된 손실일 수 있다.**
