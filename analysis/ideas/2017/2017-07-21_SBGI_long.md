## 5. 가장 중요한 T0 질문

“이 deal이 accretive한가?”보다 먼저:

**“이 deal이 어떤 구조로 승인될 확률이 얼마나 되는가?”**

를 물어야 했다.

Event-driven valuation은:
**close probability × close value + break probability × standalone value - break/legal cost**
로 해야 한다.

원문은 close case valuation은 자세했지만 break case가 약했다.

## 6. 재사용 교훈

1. merger Long은 accretion보다 regulatory probability부터 본다.
2. regulator-friendly administration도 applicant conduct risk를 없애지 않는다.
3. pro forma EBITDA는 close probability로 할인한다.
4. dual-class owner-operator의 aggressive deal behavior를 governance risk에 넣는다.
5. event failure 시 standalone balance sheet와 reputation damage를 별도 계산한다.

### 한 문장 교훈

> **M&A 투자에서 가장 정교한 synergy model도 ‘거래가 닫힌다’는 한 줄의 확률이 틀리면 0이 된다.**
