# 1. 핵심 구조 — Deal break 후 standalone value

Anthem-Cigna deal break 상황에서는 merger-arb와 standalone long을 섞으면 안 된다.

분석식은:
**Standalone earnings value + breakup 이후 capital return option - litigation/integration cost = standalone equity value**

원문은 deal break 뒤에도 Cigna 자체가 싸고, 큰 buyback 여력이 있다는 점을 봤다.

# 2. 원문 논지
연방법원이 Anthem의 Cigna 인수를 막은 뒤 deal completion 가능성을 5%로 낮게 봤다. Deal이 무산되면 Cigna가 약 $7bn을 자사주 매입해 시총의 약 18.8%를 줄이고, 2018 EPS $11.92에 14x를 적용하면 $167이 가능하다고 계산했다. 2016 약했던 Group Disability & Life earnings 회복과 breakup fee, 새로운 M&A도 upside로 봤다.

핵심 insight: Managed care는 ASO/risk/PBM을 분리하고 operating EPS와 market multiple을 별도 확률변수로 관리해야 한다.

# 3. 당시 시장 기대
시장은:
- Anthem 거래 불확실성
- 소송/분쟁
- standalone 성장성
- capital return
을 동시에 할인하고 있었다.

따라서 좋은 논지는 “deal이 깨진다/안 깨진다”보다 **깨져도 standalone 가치가 충분한가**를 봐야 했다.

# 7. 실제 성과
Anthem 거래는 2017년 5월 종료됐고 Cigna는 즉시 자본환원 계획을 강화했다. Breakup-fee 소송은 간단한 즉시 현금화 촉매가 아니었지만 standalone business와 buyback이 주가를 끌어올렸다. 2017년 말 주가는 약 $203으로 $167 standalone target을 크게 넘어섰고, 2018년에는 Express Scripts 인수를 발표했다.

약 $143~144에서 2017년 말 약 $203, 대략 **+40%**. 후속 글에서는 약 1년 뒤 +32% 청산을 언급했다.

# 8. 성공 메커니즘
**Deal overhang 해소 → standalone earnings 재평가 → buyback/capital return 기대 → multiple 정상화.**

이 사례의 장점은 catalyst 하나가 실패하면 thesis가 0이 되는 구조가 아니라는 점이다.

# 9. 첫 확인/반증
- 2017-05-12 — Cigna가 Anthem merger agreement 종료와 대규모 자사주 매입을 발표. No-deal standalone case가 실제 실행경로로 전환됐다.

# 10. Counterfactual
실패조건:
1. deal break 비용이 예상보다 큼
2. standalone EPS/FCF 악화
3. buyback 미집행
4. medical-cost trend 악화
5. litigation이 장기 자본배분을 묶음

# 11. 재사용 규칙

2. Buyback 규모보다 average purchase price와 leverage를 본다.
3. Event overhang 제거와 business improvement를 분리한다.
4. 목표가 도달과 catalyst 인과를 별도 기록한다.
