# Sprint (S) — 2014-08-06 VIC Long

## 0. Snapshot
| 항목 | 내용 |

# 1. 투자논지의 구조

이 Long은 세 가지를 샀다.

1. **SoftBank 자본지원**
2. **2.5GHz spectrum의 전략가치**
3. **Marcelo Claure 중심의 운영개선 가능성**

중요한 점은 이 셋을 하나의 가치로 합치면 안 된다는 것이다.

**Spectrum asset value  
+ operating turnaround value  
+ strategic support option  
- buildout cost  
- cash burn  
- time discount  
= equity value**

# 2. 원문 논지

T-Mobile 인수 시도가 무산되고 Dan Hesse가 교체된 직후, 시장은 Sprint의 과거 실패만 반영하고 SoftBank·Marcelo Claure 운영개선과 excess spectrum을 거의 가치에 넣지 않는다고 봤다. 45.7bn MHz-POPs의 사용되지 않는 spectrum과 2.5GHz depth가 향후 Spark/network advantage를 만들고, postpaid net adds가 2015년부터 플러스로 돌아서면 $10 이상이 가능하다고 주장했다.

핵심 insight: 무선통신에서는 spectrum의 장부·auction 가치보다 실제 network/customer economics와 strategic monetization 경로를 구분해야 한다.

# 3. 당시 시장 기대

시장은 Sprint를:
- 약한 network
- 높은 churn
- 지속되는 cash burn
- 경쟁력 낮은 standalone carrier
로 봤다.

Long은 2.5GHz와 SoftBank가 이 구조를 바꿀 수 있다고 판단했다.

# 4. Causal chain

**SoftBank capital  
→ network build / 2.5GHz 활용  
→ 품질 개선  
→ churn 하락 / subscriber 회복  
→ EBITDA/FCF 개선  
→ spectrum 가치 현실화  
→ rerating**

실제 운영개선은 일부 있었지만 이 chain이 충분히 빠르게 완성되지는 않았다.

# 8. 실제 성과
운영개선은 실제 나타났다. FY2015 adjusted EBITDA는 약 $8.1bn으로 36% 증가했고 postpaid net adds는 1.2m+, churn도 개선됐다. FY2016 adjusted FCF는 +$607m, FY2017은 +$945m으로 2년 연속 positive가 됐다. 주가도 FY2017 고점 $9.65까지 회복했다. 그러나 near-term $10+와 장기 2~3x는 충분히 달성되지 않았고, spectrum의 최대 가치는 결국 Sprint standalone보다 T-Mobile 합병에서 실현됐다.

약 $6에서 FY2017 고점 $9.65까지 상승했지만, 원문의 near-term $10+와 장기 2~3배는 평가 horizon 내 달성하지 못했다.

# 9. 가장 중요한 오류

**Spectrum asset value를 standalone monetization 속도보다 앞세운 것.**

2.5GHz는 훗날 T-Mobile에서 큰 가치를 증명했지만 Sprint 자체는 그 가치를 충분히 빠르게 FCF로 바꾸지 못했다.

# 10. 최초 확인/반증
- 2016-05-03 — FY2015 결과에서 adjusted EBITDA $8.1bn, 1.2m+ postpaid net adds와 churn 개선이 확인되며 turnaround가 숫자로 검증됐다.

앞으로는:
- churn
- network quality
- subscriber net adds
- CapEx efficiency
- FCF burn
이 spectrum SOTP보다 우선한다.

# 11. Counterfactual
2~3배가 현실화되려면:
1. 2.5GHz buildout 빠른 성공
2. churn 구조적 개선
3. subscriber share gain
4. EBITDA/FCF 전환
5. SoftBank 추가지원 없이도 standalone viability
가 필요했다.

# 12. 재사용 규칙
1. 전략자산의 가치는 운영 monetization 속도로 할인한다.
2. 대주주 지원은 permanent value가 아니라 financing option이다.
3. Turnaround는 고객 KPI→FCF까지 연결돼야 한다.
4. “자산은 맞았다”와 “주식이 맞았다”를 분리한다.
5. near-term target과 long-term SOTP를 같은 thesis로 섞지 않는다.
