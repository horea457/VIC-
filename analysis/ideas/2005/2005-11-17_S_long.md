# 1. Sprint의 돈 버는 구조

Sprint는 가입자 기반 반복매출 사업이지만 실제 주주가치는:

**Subscribers × ARPU  
→ service revenue  
- network opex / customer care / device subsidy  
= EBITDA  
- network CapEx  
- handset cash outflow  
- interest  
= FCF  
→ debt / buyback / M&A  
→ equity value**

로 봐야 한다.

통신은 고정비가 크기 때문에 **가입자와 churn 방향**이 매우 중요하다. 고객이 빠지면 같은 network 비용을 더 적은 고객이 부담하고, 신규고객 유치를 위해 마케팅·보조금도 늘어난다.

# 2. Nextel 합병 후 당시 기대

원문은 Sprint-Nextel 통합 뒤:
- 낮은 leverage
- ILEC spin
- buyback capacity
- 규모의 경제
를 upside로 봤다.

하지만 여기에는 큰 숨은 가정이 있었다.

> **통합이 최소한 고객경험과 churn을 악화시키지 않는다.**

낮은 leverage는 통합이 잘될 때 buyback 재원이지만, 통합이 실패하면 **생존 buffer**가 된다.

# 3. 원문 논지
Sprint-Nextel 합병 후 wireline(후일 Embarq)을 2Q06에 분리해 약 $8bn debt를 함께 넘기면 wireless balance sheet가 매우 저레버리지 상태가 되고, Nextel Partners와 Alamosa를 debt로 인수한 뒤에도 leverage가 낮다고 봤다. 이후 leverage를 1.5x까지 올려 대규모 자사주를 매입하면 2007 EPS가 $2.25까지 올라갈 수 있고, 성장성 있는 pure-play domestic wireless에 15x를 주면 $37이 가능하다는 논지였다. 원문은 downside $2/upside $13으로 손익비가 매우 좋다고 평가했다.

핵심 insight: 무선통신에서는 spectrum의 장부·auction 가치보다 실제 network/customer economics와 strategic monetization 경로를 구분해야 한다.

# 4. Causal chain

**Nextel integration  
→ network/customer experience 안정  
→ churn 유지/하락  
→ subscriber base 유지  
→ EBITDA/FCF 증가  
→ ILEC spin + buyback  
→ per-share value 상승**

실제 실패는 이 chain의 가장 앞단인 **integration/customer economics**에서 시작됐다.

# 5. Claim-by-Claim
## C1. ILEC spin
**당시 주장** wireline 분리는 약 $8bn debt를 넘기고 wireless 자산을 해방시킨다.

**근거** Sprint-Nextel 합병 후 wireline(후일 Embarq)을 2Q06에 분리해 약 $8bn debt를 함께 넘기면 wireless balance sheet가 매우 저레버리지 상태가 되고, Nextel Partners와 Alamosa를 debt로 인수한 뒤에도 leverage가 낮다고 봤다. 이후 leverage를 1.5x까지 올려 대규모 자사주를 매입하면 2007 EPS가 $2.25까지 올라갈 수 있고, 성장성 있는 pure-play domestic wireless에 15x를 주면 $37이 가능하다는 논지였다. 원문은 downside $2/upside $13으로 손익비가 매우 좋다고 평가했다.

**숨은 가정** spin이 세금·financing 계획대로 완료되고 wireless earnings가 유지

**반증조건** spin 이후에도 wireless operating deterioration

**실제 결과** Embarq spin은 실제 2006년 5월 완료됐다.

**판정** 적중

**교훈** ILEC spin 가설은 'spin 이후에도 wireless operating deterioration'를 사전 반증조건으로 저장하고 사업·이벤트·가격 판정을 분리한다.

# 8. 실제 성과

기업행위 자체는 상당 부분 실행됐다. Sprint-Nextel 거래는 2005년 8월 완료됐고 Embarq spin도 2006년 5월 완료됐다. 그러나 핵심 operating integration이 실패했다. 서로 다른 CDMA·iDEN망, customer service와 handset 문제로 가입자와 브랜드가 훼손됐고 4Q07에는 Nextel 관련 goodwill 등에 $29.7bn 비현금 손상차손을 인식했다. 즉 debt capacity와 buyback을 먼저 계산했지만, 합병 후 고객·network economics가 유지된다는 가장 중요한 선행조건이 무너졌다.

$24.27 진입 뒤 통합 실패와 가입자 악화로 equity가 크게 훼손됐다. Sprint 2010 10-K 성과표 기준 2005년 말 $100 투자액은:
- 2008년 말 $8.61
- 2010년 말 $19.90

수준이었다.

# 9. 최초 thesis break

- 2007-02-28 — Sprint가 2006 실적과 함께 가입자·운영문제를 드러내고 Nextel 통합 부진이 단순 일시적 문제가 아님이 확인되기 시작했다. 4Q07 $29.7bn goodwill impairment에서 논지 실패가 사실상 확정됐다.

첫 반증은 valuation이 아니라:
- churn
- subscriber losses
- network quality
- integration execution
에서 찾았어야 한다.

# 10. 왜 buyback 논리가 무너졌나

원문은 낮은 leverage를 자본환원 capacity로 봤다.

하지만 실제로는:

**Integration failure  
→ customer loss  
→ EBITDA/FCF pressure  
→ capital needs 증가  
→ leverage capacity가 buyback이 아니라 생존재원으로 전환**

됐다.

즉 balance-sheet 여력은 **운영이 안정적일 때만 shareholder return option**이다.

# 11. Knowability

당시 완전히 예측하기 어려웠던 것은 통합 실패의 정확한 크기다.

하지만 빠르게 관찰 가능했던 것은:
- churn 상승
- network/customer service 문제
- subscriber net loss
- integration cost
였다.

따라서 실패를 단순 unforeseen event로 처리하기보다 **초기 운영 반증 후 thesis를 유지했는지**를 본다.

# 12. Counterfactual

$37 thesis가 맞으려면:
1. Nextel integration이 고객경험을 훼손하지 않음
2. churn 안정
3. subscriber base 유지
4. CapEx/integration cost 통제
5. FCF가 실제 증가
6. 이후 buyback이 intrinsic value 이하에서 집행
이 필요했다.

# 13. 재사용 규칙

1. M&A synergy보다 **integration KPI**를 먼저 본다.
2. 낮은 leverage는 자동 buyback capacity가 아니다.
3. 통신에서 churn은 단순 KPI가 아니라 FCF leading indicator다.
4. 고정비 사업의 downside는 고객감소 시 비선형적이다.
5. 자본환원 thesis는 사업 안정성이 확인된 뒤 붙인다.
6. 합병 후 첫 4~6분기의 customer economics를 최우선으로 추적한다.
