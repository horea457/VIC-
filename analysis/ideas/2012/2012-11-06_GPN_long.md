# 1. 사업구조 — Global Payments는 pure network보다 merchant economics에 가깝다

Global Payments는 merchant acquiring / processing에 가까운 결제사업자다.

핵심 경제식은:

**Merchant volume  
× merchant processing spread  
- network / interchange pass-through  
- ISO / partner payments  
- technology / support  
- integration / interest cost  
= equity FCF**

Mastercard 같은 network보다:
- merchant retention
- software attach
- partner economics
- M&A integration
- leverage
의 영향이 크다.

따라서 낮은 FCF multiple만 볼 게 아니라 **인수 후 주당 FCF와 debt**까지 봐야 한다.

# 2. 원문 투자논지

보안침해와 캐나다 가격경쟁으로 눌린 GPN을 약 10배 2013 FCF, 11배 P/E, 6배 EBITDA에 샀다. 미국 56%·캐나다 15%·유럽 22%·아시아 7%의 매출과 international EBITDA 45%를 가진 6위 미국 acquirer였다. $250m 순현금과 2.5배까지의 레버리지 여력을 이용하면 $600~700m을 추가 조달해 시가총액 약 20%를 매입할 수 있고, 캐나다 margin 안정과 보안사고 종결 뒤 14~15배 FCF인 $60~65로 재평가되거나 Fiserv·PE에 인수될 수 있다고 봤다.

# 8. V9 Postmortem

결제주는 다음 bridge로 본다.

1. **Volume:** TPV / GPV / GDV가 실제로 성장하는가.
2. **Mix:** branded / unbranded, domestic / cross-border, merchant mix가 어떻게 바뀌는가.
3. **Take-rate quality:** incentive·partner payment·network fee를 뺀 net economics가 유지되는가.
4. **Margin:** gross profit 성장보다 transaction / contribution margin이 중요한가.
5. **SBC / dilution:** 기업 성장률이 주당가치 성장률로 남는가.
6. **M&A:** 매출성장 유지가 아니라 주당 FCF accretion이 있는가.
7. **Valuation:** 같은 20% 성장도 12x와 35x는 전혀 다른 투자다.
8. **Short:** 단순 고평가가 아니라 어떤 operating metric이 깨져야 하는지 사전 정의한다.
