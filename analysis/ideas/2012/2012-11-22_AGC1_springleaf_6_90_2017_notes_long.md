# Springleaf Finance 6.90% Notes due 2017 (AGC1) — 2012-11-22 VIC Long

> **Research as-of:** 2026-09-18. 원 SQL Long과 실제 방향이 일치하나 security는 equity가 아닌 **senior unsecured debt**다.

> **결론:** 2009 아이디어가 panic recovery였다면 2012 아이디어는 이미 Springleaf로 재편된 consumer lender의 **credit normalization**을 사는 거래였다. 6.90% 2017 note를 약 87에 사서 10% YTM과 spread tightening을 노렸다. 이후 Springleaf는 2013 새 2021/2023 notes를 발행해 $700m 규모 2017 notes를 exchange했고, cash repurchase도 진행했다. 2017에는 약 $466m을 추가 repurchase했고 잔여 2017 notes는 maturity에 상환됐다. 원문의 refinancing thesis는 매우 강하게 적중했다.

## 4. 왜 좋은 credit trade였는가

**Return = coupon carry + pull-to-par + spread tightening**

세 요소가 동시에 있었다.

equity처럼 terminal earnings를 맞힐 필요 없이 **issuer가 2017까지 refinancing을 확보하면 payoff가 상당 부분 고정**됐다.

## 6. 재사용 가능한 교훈

1. credit trade는 equity upside보다 **maturity schedule**을 먼저 본다.
2. 87에 사는 par bond는 spread tightening 없이도 pull-to-par가 있다.
3. refinancing issuance는 fundamental catalyst 자체다.
4. exchange offer는 holder 선택에 따라 cash-flow path가 달라진다.
5. exact security cash flow가 없으면 realized IRR을 과도하게 정밀화하지 않는다.
