# 1. 사업구조 — Google의 핵심 자산은 검색 intent와 distribution이다

Google의 본업은 검색광고다. 사용자가 의도를 담은 query를 입력하면 광고주는 그 commercial intent에 입찰한다.

핵심 경제식은:

**Search / YouTube advertising revenue  
- TAC  
- data-center / infra  
- R&D / sales  
= core FCF**

여기에 Cloud, YouTube subscription, Waymo 등 option value가 붙는다.

핵심 KPI는:
- query share
- revenue per query
- TAC
- default-search distribution
- YouTube monetization
- Cloud growth / margin
- capex
- regulatory remedy risk
다.

좋은 optionality 투자는 미래 옵션을 정확히 예측하는 것이 아니라 **현재 core value로 하방을 만들고 option에 낮은 가격을 지불하는 것**이다.

# 2. 원문 투자논지

# 8. V9 Postmortem

이 아이디어는 다음 축을 분리해서 판정한다.

1. **Business:** 당시 본 핵심 moat가 실제로 유지됐는가.
2. **Valuation:** entry price가 정상화 earnings / FCF에 비해 충분히 낮았는가.
3. **Optionality:** 미래 신사업에 얼마를 지불했는가.
4. **Catalyst:** 가치가 투자기간 안에 인식될 이유가 있었는가.
5. **Regulation / distribution:** 플랫폼 접근권과 규제가 economics를 어떻게 바꿀 수 있는가.
6. **Per-share value:** buyback / dilution까지 반영한 주당가치가 늘었는가.
7. **Short asymmetry:** Short라면 multiple이 높다는 사실 외에 실제 earnings/catalyst deterioration이 있었는가.
