# Chesapeake Energy (CHK) — 2011-02-08 VIC Common Stock Long

> **Idea unit:** 2011-02-08 CHK Long.  
> 핵심은 **좋은 acreage + liquids 전환 + 행동주의 + asset monetization이 실제 common equity deleveraging으로 이어지는가**이다.

## 0. Idea Snapshot

| 항목 | 내용 |
|---|---|
| 방향 | Long |
| 전략 | 25/25 plan |
| 부채 목표 | 약 25% 축소 |
| 생산 목표 | 약 25% 증가 |
| 2012 drilling capital | 약 70%를 liquids로 |
| 주요 촉매 | JV, asset monetization, Icahn/이사회 규율 |
| 최종 old equity recovery | 2021년 0 |
| 최종 판정 | **실패** |

# 1. 25/25 Plan이 무엇인가

원문의 핵심은 동시에:
- debt 25% 감소
- production 25% 증가

를 달성하는 것이었다.

이를 위해:
- gas drilling 축소
- oil/NGL 비중 확대
- JV partner drilling carry
- asset sale
- 행동주의자 압력

을 활용한다고 봤다.

좋은 계획처럼 보이지만 문제는 **두 목표가 서로 자본을 경쟁한다**는 점이다.

생산을 25% 늘리려면 capex가 필요하고,
부채를 25% 줄이려면 cash가 필요하다.

# 2. Claim

## C1. Asset monetization으로 debt 25% 축소
JV·자산매각은 실제 유동성을 만들었다.

하지만 좋은 자산을 팔면:
- debt ↓
- 미래 production/FCF ↓

가 동시에 일어난다.

순부채만 줄었다고 deleveraging 성공이 아니다.

**판정: 실패**

## C2. Core drilling으로 생산 25% 성장
활동량과 생산은 개선됐지만 주당 FCF 증가로 이어지지 않았다.

**판정: 부분 적중**

## C3. Drilling capital 70%를 liquids로 전환
Oil/NGL mix 전환은 실제 진행됐다.

하지만 기존:
- gas acreage
- transport commitment
- debt
- fixed cost

가 그대로 남아 있어 gas shock을 충분히 상쇄하지 못했다.

**판정: 부분 적중**

## C4. Icahn이 자본배분을 규율
2012년 이사회 재편은 실제 발생했다.

즉 governance catalyst 자체는 맞았다.

하지만 catalyst 발생 = equity value creation은 아니었다.

**판정: 부분 적중**

# 3. 가장 중요한 숫자

2011 CFO 약 $5.90bn  
→ 2012 CFO 약 $2.84bn

으로 절반 이하 수준까지 감소했다.

이는:
- low gas
- cash flow pressure

가 25/25 plan의 자금 기반을 약화시켰음을 보여준다.

# 4. JV와 drilling carry의 함정

예를 들어 partner가 $1bn drilling carry를 제공해도 그것은:

**CHK bank account에 자유롭게 들어오는 $1bn cash**

가 아니다.

특정 개발비를 대신 내주는 자금이다.

따라서 balance-sheet 분석에서는:

**Cash consideration**  
과  
**restricted drilling carry**

를 분리해야 한다.

# 6. 핵심 오류

원문은:
**촉매가 발생한다**
를
**주당가치가 증가한다**
로 연결했다.

하지만 필요한 식은:

**Asset monetization cash  
- sold future FCF  
- required capex  
- debt/preferred/transport obligations  
= change in common equity value/share**

였다.

# 7. 재사용 가능한 교훈

1. **Asset sale proceeds와 deleveraging을 동일시하지 않는다.**
2. 매각 뒤 사라지는 생산량/FCF도 차감한다.
3. Drilling carry는 unrestricted cash가 아니다.
4. Mix shift에는 신규 capex가 든다.
5. 행동주의 catalyst는 balance-sheet math를 대신하지 않는다.
6. 분기별 순부채/주와 FCF/주가 개선되는지 확인한다.

### 한 문장 교훈

> **좋은 자산과 좋은 행동주의 촉매가 있어도, 자산매각 후 미래 현금흐름을 차감한 순부채/주와 FCF/주가 개선되지 않으면 common equity turnaround는 아니다.**
