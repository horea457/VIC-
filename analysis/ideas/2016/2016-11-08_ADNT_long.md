# Adient (ADNT) — 2016-11-08 VIC Long

> **Direction audit:** raw SQL은 Short지만 원문은 spin-off mispricing과 FY18 FCF upside를 제시한 실제 **Long**.
> **Research as-of:** 2026-09-10.

## 0. Snapshot

| 항목 | 내용 |
|---|---|
| 상황 | Johnson Controls에서 분사 직후 |
| global seating share | 약 **34%** |
| China share | 약 **45%** |
| FY17 EBITDA | 약 **$1.575bn** |
| baseline value | **$47~56** |
| FY18 earnings estimate | 약 **$10.15/share** |
| FCF-yield value | 약 **$62/share** |
| 실제 | 2017 고점 **$84.05** |
| 2018 종가 | **$15.06** |
| 최종 판정 | **초기 강한 성공 / 장기 thesis 붕괴** |

> **결론:** 분사 직후 forced selling, transition-year accounting, China JV 저평가를 잘 짚었다. 2017 주가는 $84까지 올라 단기 rerating은 강하게 성공했다. 하지만 metals/SS&M의 구조적 손실과 launch complexity가 뒤늦게 드러나며 2018 주가는 80% 급락했다. **Spin discount를 맞혀도 cost-structure quality를 틀리면 장기 성공으로 이어지지 않는다.**

### C5. FY18 normalized FCF — **실패**
gross margin이 2017 약 9%에서 2018 약 5%로 하락.

### C6. leverage easy to reduce — **지연/부분**
cash flow deterioration가 deleveraging을 어렵게 함.

## 5. 실제 가격 경로

Macrotrends:
- 2017 high **$84.05**
- 2017 close **$76.98**
- 2018 close **$15.06**
- 2018 annual change 약 **-80.4%**

따라서 단기 spin rerating과 장기 operating failure를 분리해야 한다.

---

## 6. 재사용 교훈

1. spin-off technical discount와 business-quality discount를 분리한다.
2. transition-year FCF는 launch/capex normalization을 stress한다.
3. China JV value를 standalone에 더할 때 parent cash conversion을 본다.
4. peer margin gap은 automatically closable하지 않다.
5. 초기 rerating을 장기 thesis validation으로 오해하지 않는다.

### 한 문장 교훈
> **스핀오프는 싸게 시작할 수 있지만, 싸게 시작한 이유가 단순 technical인지 실제 운영 복잡성인지 시간이 지나면 갈린다.**
