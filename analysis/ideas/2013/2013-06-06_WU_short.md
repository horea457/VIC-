# Western Union (WU) — 2013-06-06 VIC Short

> **Idea unit:** 2013-06-06 Western Union Short.  
> 핵심 질문은 **스마트폰 보급률이 실제 송금고객 전환율과 동일한가**이다.

## 0. Idea Snapshot

| 항목 | 내용 |
|---|---|
| 방향 | Short |
| 핵심 논지 | Smartphone adoption → digital network effect → WU transaction decline |
| 핵심시장 smartphone penetration 예상 | 2012 28.4% → 2015 61.7% |
| 2014 Revenue 예상 | 약 -5% |

# 1. 원문의 disruption logic

원문은 스마트폰 보급이 임계점을 넘으면:
- 더 싼 digital transfer
- 더 편한 UX
- network effect

가 결합돼 WU가 Kodak 같은 급격한 파괴를 맞을 것으로 봤다.

기술 방향은 맞았다.

하지만 필요한 연결은:

**Smartphone 보유  
→ 은행/월렛 접근  
→ KYC 통과  
→ 송금 신뢰 형성  
→ 상대방 수취계좌 존재  
→ 현금 대신 digital 수취 선택  
→ WU 이탈**

이다.

원문은 첫 단계에서 마지막 단계로 너무 빨리 점프했다.

# 2. 원문 Claim

## C1. Smartphone 보급이 WU transaction을 줄인다
**실제:** C2C transactions는 2012 약 231m에서 2017 약 275.8m으로 약 19% 증가했다.

즉 스마트폰은 늘었지만 WU 거래도 늘었다.

**판정: 실패**

## C2. Digital network가 WU의 agent moat를 대체한다
새 앱이 더 싸고 편한 것은 맞지만 cross-border remittance는:
- KYC/AML
- recipient cash preference
- payout access
- trust
- local regulation

을 모두 해결해야 한다.

WU는 자체 digital front-end를 기존 payout network와 결합했다.

**판정: 실패**

Incumbent가 신기술을 **자기파괴가 아니라 보완재**로 흡수할 가능성을 놓쳤다.

## C3. 2014 Revenue -5%
원문은 volume -3%, price -2% 정도를 가정했다.

실제 2014 revenue는 약 +1.2%.

**판정: 실패**

Volume 감소 가정이 핵심적으로 틀렸다.

## C4. Declining earnings에 10x도 비싸다
사업이 빠르게 감소할 것으로 봤기 때문에 10x valuation도 안전하지 않다고 판단했다.

실제 5년 주가는 약 +45.4%.

**판정: 실패**

낮은 multiple에 이미 상당한 악화가 반영돼 있었다.

# 3. 최초 반증신호

2013 C2C transaction이 약 +5% 증가했다는 사실이다.

원문의 핵심 메커니즘은:
**스마트폰 보급 → transaction 감소**
였다.

그런데 transaction 자체가 증가했다.

이건 매우 명확한 thesis break다.

# 4. 왜 Kodak analogy가 틀렸나

사진필름은:
- 더 좋은 디지털카메라가 나오면
- 소비자가 즉시 촬영방식을 바꿀 수 있다.

국제송금은:
- 보내는 사람
- 받는 사람
- 두 나라 규제
- 두 나라 금융인프라
- 신뢰
- 현금선호

가 동시에 바뀌어야 한다.

즉 adoption friction이 훨씬 크다.

# 6. 재사용 가능한 교훈

1. **기술 penetration과 고객 churn은 다르다.**
2. **Adoption funnel을 단계별로 모델링한다.**
3. **양쪽 사용자가 필요한 서비스는 한쪽 기술보급률만 보면 안 된다.**
4. **Incumbent가 신기술을 기존 network에 붙일 가능성을 본다.**
5. **Kodak analogy는 switching friction이 같은 산업에서만 쓴다.**
6. **낮은 multiple의 implied decline을 먼저 역산한다.**

## 최종 한 문장

> **기술이 더 좋다는 사실과 기존 기업의 매출이 빠르게 사라진다는 사실 사이에는 고객행동·규제·수취인프라라는 긴 전환 funnel이 있다.**
