# 1. 사업구조 — 자동차 기업은 cycle, obligations, optionality를 함께 봐야 한다

GM의 주주현금흐름은 차량 판매 gross profit만으로 설명되지 않는다.

**Auto operating profit  
+ captive finance contribution  
- capex  
- pension / warranty / restructuring cash  
- interest / working-capital needs  
= equity FCF**

파산 전 Old GM common과 파산 후 New GM common은 같은 이름이어도 완전히 다른 증권이다.

또한 Cruise 같은 AV option은 별도 확률가중해야 한다.

**Core auto value  
+ probability-adjusted tech option  
- pension / debt / other obligations  
= common equity value**

워런트는 다시 strike·만기·배당조정 때문에 common과 다른 payoff다.
