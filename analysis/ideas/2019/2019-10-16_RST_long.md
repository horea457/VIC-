## 4. Claim Map

### C1. Lexia는 RST의 crown jewel이다 — 강한 성공
2020 strategic buyer가 whole company를 $792m equity value에 인수했다.

### C2. Lexia standalone value $600~800m — 강한 성공 방향
whole-company transaction value가 약 $792m였다는 점이 원문의 asset-value band와 매우 가깝다.

### C3. legacy language business는 zero가 아니다 — 성공 방향
consumer subscriber base도 SaaS transition 후 안정화됐고 whole-company buyer에게 residual value를 제공했다.

### C4. activist / board pressure가 value unlock을 만든다 — 성공
원문은 sale, split, spin을 2020 catalyst로 제시했고 실제 sale process가 열렸다.

### C5. ELL launch가 growth acceleration을 만든다 — 부분
takeout이 빨리 발생해 standalone 장기 효과를 완전히 관측하지 못했다.

### C6. Base +90% — 거의 실현

## 7. Hidden Assumptions

1. private EdTech multiple이 유지된다.
2. Lexia의 growth가 20~30%를 유지한다.
3. school-budget / sales-cycle risk가 악화되지 않는다.
4. corporate cost와 legacy language drag가 Lexia value를 크게 잠식하지 않는다.
5. board가 value unlock을 실제로 실행한다.

이 중 가장 중요한 5번이 실제로 발생했다.

## 8. 재사용 체크리스트

1. legacy brand가 company perception을 왜곡하는지 확인한다.
2. segment mix가 바뀌면 company-level historical multiple을 버린다.
3. hidden asset은 standalone ARR/bookings/retention으로 평가한다.
4. activist ownership은 board seat와 실제 strategic review 가능성을 본다.
5. asset value > EV이면 sale/spin route가 있는지 확인한다.
6. Bull case보다 Base case와 actual takeout을 비교한다.
