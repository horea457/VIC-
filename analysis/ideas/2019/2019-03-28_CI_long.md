# 1. Express Scripts 인수 후 무엇을 봐야 하나

Express Scripts 인수로 Cigna는 보험사에서 **보험 + PBM/Evernorth 복합 health-services 기업**으로 변했다.

핵심 분석은:
**Organic earnings + synergy - financing cost - integration cost = incremental FCF**

그리고:
**Incremental FCF / acquisition capital = acquisition ROIC**

다.

단순 EPS accretion은 debt와 낮은 target multiple로도 만들 수 있어 충분하지 않다.

# 2. 원문 논지
Express Scripts 인수 직후 Cigna가 약 10x forward earnings로 S&P 17x 대비 40% discount인데 2009~18 EPS CAGR 15%를 이어갈 수 있다고 봤다. PBM rebate 규제, Medicare for All, 약 4x debt/EBITDA가 과도한 우려이며 integration·deleveraging 후 mid-2x leverage와 2021 EPS $20~21, 17x multiple로 $350이 가능하다고 주장했다.

핵심 insight: Managed care는 ASO/risk/PBM을 분리하고 operating EPS와 market multiple을 별도 확률변수로 관리해야 한다.

# 3. 당시 시장이 할인한 것
- Express Scripts integration risk
- PBM 규제/rebate transparency
- 높은 debt
- conglomerate discount
- synergy realization

따라서 이 투자에는 **business thesis와 multiple thesis**가 동시에 있었다.

# 4. Causal chain
**ESRX client retention + synergy → Evernorth earnings 증가 → EPS/FCF 증가 → debt reduction/buyback → per-share growth → rerating**

문제는 마지막 rerating이 필수였다는 점이다.

# 8. 실제 성과
운영예측은 놀랍도록 정확했다. Cigna의 2021 adjusted EPS는 $20.47로 원문 $20~21 범위에 정확히 들어왔고, debt ratio도 인수 직후보다 낮아졌다. 그러나 2021년 말 주가는 약 $230으로 $350 target에 크게 못 미쳤다. 즉 'EPS를 맞혔다=주식 목표가를 맞혔다'가 아니었다. PBM 정치위험·복합사업 할인·capital allocation을 반영한 P/E는 원문이 기대한 17x까지 가지 않았다.

$160에서 2019년 말 약 $204(+28%), 2021년 말 약 $230(+44%).  
하지만 원문 2021년 목표 **$350은 크게 미달**했다.

즉:
- 운영 EPS/FCF thesis: 강하게 적중
- target multiple/timing: 실패

# 9. 핵심 오류
**15% EPS CAGR이 곧 높은 P/E 재평가로 이어진다고 본 것.**

시장은 Evernorth 성장에도:
- PBM 규제
- 복합기업 discount
- capital intensity
를 낮은 multiple로 반영할 수 있었다.

# 10. 첫 확인/반증
- 2022-02-03 — 2021 adjusted EPS $20.47가 발표돼 operating thesis는 사실상 완전 검증됐지만 주가는 $350과 크게 괴리되어 multiple thesis 실패가 확정적으로 드러났다.

운영실적이 맞는데도 multiple이 오르지 않는다면 “시장이 틀렸다”가 아니라 **시장 discount가 구조적인지** 재평가해야 했다.

# 11. Counterfactual
$350이 현실화되려면:
1. EPS CAGR 실현
2. PBM client retention
3. synergy cash conversion
4. debt reduction
5. 규제 discount 완화
6. target P/E rerating
이 동시에 필요했다.

# 12. 재사용 규칙
1. M&A accretion은 EPS가 아니라 incremental FCF/ROIC로 본다.
2. PBM 성장과 PBM multiple을 별개로 본다.
3. 사업예측 성공과 주가목표 성공을 분리한다.
4. 성장률과 rerating을 이중으로 더하지 않는다.
5. 합병 후 debt reduction 속도를 추적한다.
