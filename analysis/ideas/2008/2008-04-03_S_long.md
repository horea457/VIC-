# Sprint (S) — 2008-04-03 VIC Long

## 0. Snapshot
| 항목 | 내용 |
|---|---|
| Thesis | QChat·network turnaround 또는 breakup $12~17 Long |
| 실제 결과 | 약 $6 부근에서 $12.44~17을 제시했지만 2008 금융위기와 Sprint 운영악화 속 주가는 $2 안팎까지 하락. 회복 thesis 실패. |
| 판정 | **실패한 turnaround·asset-value trap** |

# 1. Spectrum은 왜 현금이 아닌가

Sprint의 spectrum은 희소한 전략자산이었다. 하지만 spectrum 가치는:

**Spectrum MHz-pop value  
× monetization probability  
× buyer/partner probability  
- network build cost  
- time discount**

로 봐야 한다.

주파수 면허 자체가 고객경험·ARPU·FCF를 만들지는 않는다. 기지국, backhaul, handset ecosystem, network optimization이 필요하다.

# 2. 원문 논지

Nextel rebanding과 vocoder 문제로 생긴 network quality 악화가 이미 대부분 해결됐는데 customer perception과 sell-side가 이를 늦게 반영하고 있다고 봤다. QChat으로 iDEN 고객을 CDMA로 이전하고 새 handset·Dan Hesse 광고가 gross adds와 retention을 회복시킬 것이라 예상했다. 만약 turnaround가 늦어져도 2.5GHz/iDEN spectrum, long-distance fiber, Boost와 subscriber asset을 분리 매각하면 $12 이상 가치가 있다고 주장했다.

핵심은 QChat·network turnaround 또는 breakup value가 하방을 만든다는 것이었다.

# 3. 당시 시장 기대

시장은 이미 Sprint의:
- 가입자 이탈
- network 품질
- Nextel 통합 후유증
을 크게 할인하고 있었다.

Long은 “운영이 조금만 정상화되거나 asset breakup이 일어나도 $12~17”을 기대했다.

# 4. Causal chain

**QChat/network improvement  
→ churn 안정  
→ subscriber loss 완화  
→ EBITDA/FCF 회복  
→ asset value realization / rerating**

하지만 실제로는 operating deterioration이 breakup option보다 빨리 equity를 훼손했다.

# 8. 실제 성과

turnaround는 예상 시점에 오지 않았다. Sprint는 2008년에도 $1.8bn 이상의 FCF를 기록했지만 postpaid subscriber losses와 브랜드·network 문제가 지속됐다. 이미 2007년 $29.7bn goodwill impairment가 있었고, asset-value 계산과 달리 spectrum·subscriber·long-distance 자산은 독립적으로 쉽게 분리·현금화되지 않았다. 주가는 $12~17이 아니라 $2 안팎으로 내려갔다.

약 $6 부근에서 $12.44~17을 기대했지만 주가는 2008년 위기와 운영악화 속 $2 안팎까지 하락했다.

# 9. Asset-value trap의 구조

**좋은 자산  
≠ 좋은 회사  
≠ 좋은 common equity**

이다.

특히 높은 고정비와 약한 고객 economics에서는:
- asset value는 장기적
- cash burn은 즉시
라는 duration mismatch가 생긴다.

# 10. 최초 반증

- 2008-05-12 — Sprint의 1Q08 subscriber losses와 약한 outlook이 확인되면서 customer perception lag가 아니라 실제 영업악화가 계속되고 있음이 드러났다.

이 시점에 breakup value가 아니라 **subscriber/churn/FCF**를 우선해야 했다.

# 11. Counterfactual

성공하려면:
1. QChat/network quality 개선
2. churn 안정
3. subscriber loss 둔화
4. FCF burn 축소
5. spectrum buyer/partner 출현
6. asset monetization이 balance-sheet 손상보다 빨리 진행

돼야 했다.

# 12. 재사용 규칙

1. Spectrum SOTP에는 buyer probability와 time discount를 붙인다.
2. Asset value보다 cash-burn runway를 먼저 계산한다.
3. Turnaround에서 customer KPI가 개선되지 않으면 asset thesis를 축소한다.
4. Breakup value는 catalyst 없는 하방이 아니다.
5. 높은 고정비 사업에서는 운영악화 속도가 asset monetization보다 빠를 수 있다.
