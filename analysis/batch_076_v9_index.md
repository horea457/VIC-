# PART F — Batch 076 공통 분석식

### Melting-Ice-Cube SOTP

**Equity value = hard assets + cash - liabilities - future operating erosion - reinvestment leakage**

### Turnaround Valuation

**Fair value = normalized earnings × justified multiple**, not peak temporary earnings × peer peak multiple.

### Recurring-Care Platform

**Strategic value = recurring contract cash flow + cash - debt + buyer synergies**

### M&A Compounder

**Per-share compounding = organic FCF + acquisition value creation - purchase premium - dilution - leverage cost - impairment**

### Accounting-Risk Long

**Investable value = business value × reporting credibility × financing continuity**

# PART G — Batch 076 재사용 체크리스트

1. executive recruitment를 audited financial evidence보다 높게 평가하지 않는다.
2. late filer는 accounting-control thesis를 별도로 만든다.
3. melting-core SOTP에는 annual erosion rate를 넣는다.
4. asset sale의 속도가 IRR을 좌우한다.
5. hard assets가 실재해도 retained cash의 사용처를 추적한다.
6. reverse split 전후 share price를 직접 비교하지 않는다.
7. ticker punctuation까지 legal identity를 검증한다.
8. pandemic peak earnings를 normalized earnings와 분리한다.
9. strategic takeout price는 private-market valuation의 강한 falsifier다.
10. recurring revenue의 계약기간과 counterparty quality를 본다.
11. M&A compounder는 consolidated EBITDA보다 per-share FCF를 본다.
12. goodwill impairment를 과거 acquisition ROIC의 사후검증으로 쓴다.
