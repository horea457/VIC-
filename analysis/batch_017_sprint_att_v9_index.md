# 2. Batch 017의 핵심 질문

이 배치의 가장 중요한 질문은:

> **좋은 통신자산의 가치가 지금 내가 가진 증권에 실제로 언제 귀속되는가?**

통신업의 기본 주당가치 chain은:

**가입자 × ARPU  
→ service revenue  
- network/customer acquisition cost  
= EBITDA  
- network CapEx  
- device cash outflow  
- interest  
= FCF  
→ debt / M&A / buyback / dividend  
→ FCF/share  
→ common equity value**

이다.

Sprint는 이 chain의 앞단인 **subscriber/customer economics와 spectrum monetization**이 문제였다.

AT&T는 core connectivity FCF는 비교적 안정적이었지만 **DirecTV·Time Warner/WarnerMedia 같은 자본배분과 기업구조 변경**이 주주 귀속가치를 바꿨다.

# 3. Sprint — Spectrum은 좋은 자산이었지만 Sprint common은 왜 약했나

Sprint의 2.5GHz spectrum은 훗날 T-Mobile에서 매우 높은 전략가치를 증명했다.

하지만 spectrum은 현금이 아니다.

정확한 식은:

**Spectrum value  
× monetization probability  
× buyer / partner probability  
- network build cost  
- time discount  
= shareholder-realizable value**

다.

Sprint 자체가 spectrum 가치를 monetization하려면:
- 기지국
- backhaul
- device ecosystem
- network optimization
- 충분한 가입자기반

이 필요했다.

즉:

> **좋은 생산요소 ≠ 좋은 운영회사 ≠ 좋은 common equity**

였다.

---

# 4. Sprint 2005 — Nextel M&A의 첫 번째 실패

2005 Long은 Nextel 합병 후:
- 낮은 leverage
- ILEC spin
- buyback
- synergy

를 upside로 봤다.

하지만 가장 중요한 선행조건은:

> **통합이 고객경험을 망가뜨리지 않는 것**

이었다.

실제 chain:

**Integration 문제  
→ network/customer experience 악화  
→ churn 상승  
→ subscriber loss  
→ fixed-cost absorption 악화  
→ EBITDA/FCF 약화  
→ balance-sheet capacity가 buyback이 아니라 survival buffer로 전환**

됐다.

### 핵심 교훈

낮은 leverage는 자동 자본환원 capacity가 아니다.

운영이 흔들리면 같은 cash/debt capacity가:
- buyback 재원
에서
- 생존재원
으로 바뀐다.

# 5. Sprint 2008 — Asset-value trap

2008 Long은:
- QChat
- network turnaround
- spectrum
- breakup value

를 하방으로 봤다.

하지만 문제는 **시간**이었다.

Asset monetization은 느리고,
cash burn은 즉시 발생했다.

따라서:

**Long-duration asset value  
vs short-duration cash burn**

의 duration mismatch가 equity를 훼손했다.

### 재사용 원칙

> Breakup value는 catalyst가 없으면 진짜 downside floor가 아니다.

---

# 6. Sprint 2010 Short — Operating short와 Terminal short의 차이

2010 Short는 상당히 많은 것을 맞혔다.

- 고비용구조
- subscriber decline
- FCF 압박
- standalone economics 취약성

하지만 terminal thesis에서는 SoftBank 같은 전략적 rescue를 충분히 넣지 않았다.

실제:
- 주가 2011년 $2대까지 하락
- 2012 SoftBank 거래 발표
- survival/recapitalization

으로 이어졌다.

### 정확한 Short expected value

**Standalone downside  
- rescue probability  
- takeover premium risk  
- squeeze / carry cost**

를 계산해야 한다.

즉:

> **회사가 나빠진다 ≠ 보통주가 0이 된다.**

이다.

2.5GHz는 훗날 가치를 증명했지만 Sprint standalone FCF로 충분히 빠르게 전환되지 않았다.

# 8. Sprint 2016 Short — 회계분석은 맞고 주식은 틀린 사례

2016 Short의 가장 좋은 부분은 **handset lease accounting**이었다.

단말기를 먼저 현금으로 사고 고객에게 lease하면 현금은 먼저 나가지만 회계상 비용은 기간에 걸쳐 인식될 수 있다.

따라서:

**EBITDA  
- network CapEx  
- handset cash outflow  
- interest  
= economic FCF**

를 봐야 했다.

원문은 normalized FCF 약 -$4.2bn 수준을 공격했다.

이 분석 자체는 좋았다.

그러나:

> **회계/FCF 분석이 맞다 = equity가 0으로 간다**

는 아니었다.

T-Mobile은 Sprint spectrum에 큰 strategic value를 뒀다.

# 10. AT&T — 안정적인 FCF가 왜 장기 초과수익을 보장하지 않았나

AT&T의 connectivity 사업은 Sprint보다 훨씬 안정적이었다.

문제는 FCF 자체보다 **FCF의 재배분**이었다.

기본식:

**Wireless/Fiber FCF  
+ Media FCF  
- CapEx  
- interest  
- dividend  
= residual FCF  
→ debt reduction / M&A / buyback**

이다.

AT&T의 핵심 질문은:

> **좋은 통신현금흐름을 어디에 재투자했는가?**

였다.

# 11. AT&T 2018 — 가격은 성공, Time Warner 전략은 혼합

2018 Long은 Time Warner 인수 직후:
- FCF
- deleveraging
- 배당 후 잔여현금

을 중심으로 봤다.

실제 2019말 약 $39.08로 $40 목표에 거의 도달했다.

높은 배당까지 포함하면 18개월 성과는 좋았다.

하지만 장기적으로:
- DirecTV
- WarnerMedia

는 결국 분리됐다.

따라서:

**Price/FCF thesis 성공  
≠ M&A capital allocation 성공**

이다.

# 12. AT&T 2020 Short — 맞은 가격의 원인을 다시 본다

2020 Short는:
- DirecTV decline
- FCF quality
- 2022 guidance skepticism

을 봤다.

주가는 COVID 때 급락해 target zone에 들어왔다.

그러나:
- pandemic shock는 원문 밖
- wireless는 예상보다 강함

이었다.

### Short attribution rule

Short 성공은 최소 세 부분으로 나눈다.

1. 예상한 fundamental deterioration
2. 예상하지 못한 external shock
3. valuation/multiple movement

그래야 운 좋게 market crash를 맞은 Short를 좋은 분석으로 착각하지 않는다.

2021-01 Long의 HBO Max subscriber thesis는 빠르게 맞았다.

그러나 WarnerMedia가 2021-05 분리되면서:

**WarnerMedia growth

- AT&T $15.85

였다.

### 핵심

> **Segment operating success ≠ Parent security success**

# 14. AT&T 2021-05 — 4일 만에 Thesis가 무효화된 사례

2021-05-13 Long은 WarnerMedia 55% valuation과 wireless/fiber를 합쳐 약 $65 SOTP를 봤다.

불과 **4일 뒤** WarnerMedia 분리 발표.

이건 단순 earnings miss가 아니다.

Corporate action은:
- 자산구성
- debt allocation
- dividend policy
- growth profile
- multiple

을 동시에 바꾼다.

즉 valuation model의 **identity**가 바뀐다.

### 올바른 대응

즉시 기존 $65 target을 폐기하고:

**RemainCo AT&T value  
+ distributed WBD value  
+ dividend  
- debt / leakage**

로 재-underwrite했어야 한다.

# 15. Spectrum 분석 프레임

앞으로 통신 spectrum은 다음 순서로 본다.

1. MHz / coverage 특성
2. 실제 capacity value
3. device ecosystem
4. buildout CapEx
5. time-to-deploy
6. subscriber monetization
7. strategic buyer universe
8. buyer willingness to pay
9. regulatory constraints
10. current balance-sheet runway

즉:

> **MHz-pop valuation만으로 common equity floor를 만들지 않는다.**

---

# 16. Churn이 왜 중요한가

통신은 고정비가 큰 사업이다.

Churn이 올라가면:

**고객감소  
→ 동일 network cost / 더 적은 customers  
→ acquisition spend 증가  
→ promotional pricing  
→ EBITDA pressure  
→ FCF pressure**

가 연쇄적으로 발생한다.

따라서 churn은 단순 customer metric이 아니라:

> **FCF leading indicator**

다.

---

# 17. EBITDA vs FCF

통신에서 EBITDA는 특히 조심해야 한다.

실제 주주경제성은:

**EBITDA  
- network CapEx  
- handset/device cash  
- spectrum cash  
- interest  
- tax  
= equity cash flow**

다.

Sprint 2016은 이 점을 잘 봤다.

AT&T에서는 여기에:
- dividend
- M&A
까지 차감해야 한다.

---

# 18. Corporate Action 분석

Spin-off, asset sale, merger가 발생하면:

**Pre-event equity  
→ retained parent security  
+ distributed security  
+ cash proceeds  
- debt transfer  
- tax / leakage**

로 바꿔야 한다.

가격차트 하나로는 total return을 계산할 수 없다.

특히 AT&T/WBD 같은 경우:
- AT&T retained value
- WBD distribution
- dividend

를 모두 포함해야 한다.
