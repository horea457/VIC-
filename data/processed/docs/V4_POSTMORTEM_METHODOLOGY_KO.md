# V4 사후분석 방법론

## 1. 원 투자논지를 먼저 고정

현재 결과를 본 뒤 과거 논지를 다시 쓰지 않는다. VIC 원문에서 핵심 Claim, 시간축, 촉매, 암묵적 가정을 먼저 분리한다.

## 2. 실제 Long/Short 방향을 본문에서 재확인

원 dump의 `is_short`가 일부 잘못돼 있으므로 사후분석 완료 사례는 `research_direction_ko`를 별도로 저장한다.

## 3. 결과를 여러 축으로 분리

- 핵심 투자논지
- 사업/산업구조
- Catalyst/Event
- 밸류에이션
- 주가
- 현재 상태

주가가 상승해도 핵심 Claim이 틀렸다면 투자논지 성공으로 처리하지 않는다.

## 4. Claim마다 실제 데이터를 붙임

각 Claim은 `당시 주장 → 핵심 가정 → 실제 결과 → 판정 → 해석`으로 저장한다.

## 5. 실패의 층위를 분리

표면 결과가 아니라 실패 메커니즘과 근본 분석 오류를 구분한다. 예: 매출 감소 → 수요 정상화 → 팬데믹 pull-forward를 구조 성장으로 외삽.

## 6. 최초 반증 신호와 반증 질문을 저장

사후 설명보다 중요한 것은 '당시에 무엇을 봤어야 했나'다. 각 사례에는 최초 반증/확인 신호와 현재 분석에 재사용할 질문을 남긴다.

## 7. 근거 자료

기업 공식 IR, SEC 등 1차 자료를 우선 사용하고 `postmortem_sources`에 링크와 핵심 근거를 저장한다.
