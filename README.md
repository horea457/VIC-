# VIC 허구 반증 연구소 — V3

VIC의 과거 투자 아이디어를 **패턴 → 기업/아이디어 → Claim → 성공·실패 해부** 순서로 탐색하는 Streamlit 연구 대시보드입니다.

## V3 데이터 현황

- VIC 아이디어: **13,656건**
- 기간: **2000–2022년**
- 자동 프로필: **13,656건**
- 검증 가능한 Claim: **32,571개**
- 상위 성공/실패 패턴: **23개** (성공 8 / 실패 15)
- 아이디어×패턴 자동 후보 연결: **3,343건**
- 세부 실패 메커니즘 taxonomy: **55개**
- 근본 분석 오류 taxonomy: **15개**
- 선행 반증 신호 taxonomy: **12개**
- 대시보드 설명: **한국어 중심**

## 핵심 탐색 흐름

`성공·실패 패턴`  
→ `해당 기업·VIC 아이디어`  
→ `기업/사업 구조`  
→ `당시 투자논지`  
→ `Claim / 암묵적 가정`  
→ `반증조건 / 선행지표`  
→ `주가 성과와 논지의 정합성`  
→ `Failure Anatomy`  
→ `당시 물었어야 할 질문`

## 중요한 해석 원칙

> **주가가 올랐다고 원래 투자논지가 맞았던 것은 아니다.**

V3의 `자동 예비판정`은 기존 데이터셋의 1·3·5년 방향조정 주가성과와 당시 VIC 논지 태그를 결합한 **탐색용 후보**입니다.

따라서 다음은 자동으로 확정하지 않습니다.

- 실제 Catalyst/Event가 실행됐는지
- 사업 경쟁력이 실제로 좋아졌거나 나빠졌는지
- 최초 반증 신호가 정확히 언제 나타났는지
- 2026년 현재 사업 상태
- 주가 결과가 원래 투자논지 때문에 발생했는지

이 값들은 외부 자료를 이용한 `정밀 검증` 단계에서 덮어쓰도록 설계했습니다.

## V3 태깅 개선

V2처럼 본문에 단어가 한 번 등장했다고 태그를 붙이지 않습니다.

- 강한 thesis 표현에 높은 가중치
- 문구 반복 빈도 반영
- Catalyst 섹션 별도 가중
- 원문에서 실제 근거 문장 추출
- 각 태그를 `Claim → 가정 → 반증조건 → 선행지표`로 구조화

## 주요 화면

1. **홈** — 전체 DB와 주요 성공/실패 패턴
2. **아이디어 탐색** — 회사/티커/작성자/연도별 검색
3. **기업·아이디어 분석** — 개별 아이디어의 전체 해부
4. **성공·실패 패턴 연구소** — 패턴 → 기업 → 상세분석
5. **투자논지 라이브러리** — 반복되는 VIC 서사 탐색
6. **반증 신호** — 무엇을 먼저 모니터링해야 하는가
7. **데이터 품질** — 자동분석과 정밀검증의 경계
8. **검증 우선순위** — 실제 외부조사를 먼저 할 사례 큐

## 실행

```bash
pip install -r requirements.txt
streamlit run app/Home.py
```

Streamlit Community Cloud에서는 Main file path를 `app/Home.py`로 지정합니다.
