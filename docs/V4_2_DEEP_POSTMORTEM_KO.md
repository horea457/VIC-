# V4.2 심층 사후분석

V4.2부터 `사후분석 완료`는 단순 성공/실패 요약이 아니라 다음 순서를 따른다.

1. 기업과 사업의 경제성
2. VIC 당시 핵심 투자논지와 성립조건
3. 당시 밸류에이션과 기대수익 구조
4. 사후 실제 실적을 정량 스냅샷으로 비교
5. 사건을 시간축으로 배열
6. 사업/논지/촉매/밸류에이션/주가/현재 상태를 분리 판정
7. 잘 본 부분과 틀린 부분을 별도로 기록
8. 실패/성공 패턴, 최초 반증 신호, counterfactual question
9. 현재 다른 기업에 재사용할 체크포인트

## 신규 테이블
- `postmortem_longform`
- `postmortem_metrics`
- `postmortem_timeline`

## 원칙
주가 상승을 논지 성공으로 자동 간주하지 않는다. 당시 작성자가 실제로 주장한 mechanism과 horizon을 사후 사업 데이터와 대조한다. 숫자가 없는 경우 억지로 정량화하지 않고 자료 부재를 명시한다.
