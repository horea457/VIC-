# 대시보드 아키텍처

## 분석 흐름

`원본 VIC 아이디어 → 기업 설명 → 투자논지 요약 → Claim 분해 → 핵심 가정 → Falsifier → 최초 반증 신호 → Thesis Horizon / Event / Current → 결과 분해 → 실패 해부 → 반증 질문`

## 화면 구조

1. **홈** — 데이터베이스 전체 규모와 빠른 검색
2. **아이디어 탐색** — 시점/롱숏/이벤트/자동 논지태그 필터
3. **기업·아이디어 분석** — 기업 설명 → 투자논지 → 성공/실패 분석 흐름
4. **실패 패턴 연구소** — 반복되는 실패 메커니즘과 근본 분석 오류
5. **투자논지 라이브러리** — TAM, 네트워크 효과, 가격결정력, 영업레버리지 등 반복 서사 검색
6. **반증 신호** — 무엇이 먼저 깨졌는지 축적
7. **데이터 품질** — 원본/자동/정밀분석 상태를 분리

## 성과평가 원칙

현재 주가만으로 성공/실패를 정하지 않습니다.

- **Thesis Horizon**: 작성자가 기대한 기간 안에 핵심 명제가 실현됐는가
- **Event Resolution**: 이벤트형 투자는 이벤트 발생 여부·시점·조건을 별도로 평가
- **Current**: 장기적으로 사업과 산업구조가 어떻게 변했는가
- **Stock Outcome**: 주가 결과는 별도 축

따라서 `논지 성공 + 주가 실패`, `논지 실패 + 주가 성공`도 모두 저장할 수 있습니다.
