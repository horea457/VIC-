# V3 분석 방법론

## 목적
VIC 아이디어를 단순 수익률 데이터베이스가 아니라 **당시 주장 → 가정 → 반증조건 → 사후 결과 → 반복되는 성공/실패 패턴**으로 탐색하기 위한 연구 DB로 구성한다.

## V3에서 자동으로 처리한 범위
- 13,656개 VIC 아이디어 전량 메타데이터 정규화
- 강한 문구, 반복 빈도, Catalyst 섹션 가중치를 이용한 한국어 논지 태그
- 원문 근거 문장 추출
- 32,000개 이상의 Claim을 `주장 / 암묵적 가정 / 반증조건 / 선행지표`로 구조화
- 기존 데이터셋의 1·3·5년 성과를 Long/Short 방향에 맞게 변환
- 성공 8개 / 실패 15개 상위 패턴 후보와 아이디어 연결
- 각 아이디어의 연구 우선순위 계산

## 매우 중요한 구분
`주가 성공`과 `투자논지 성공`은 동일하지 않다.

V3의 자동 예비판정은 패턴 탐색을 위한 값이다. 실제 사업 결과, 이벤트 실행 여부, 현재 상태를 검증하지 않은 경우 정밀 성공/실패로 확정하지 않는다.

## 사용자 탐색 흐름
1. 성공/실패 패턴을 선택한다.
2. 해당 패턴과 연결된 기업·VIC 아이디어를 본다.
3. 개별 아이디어에서 당시 핵심 Claim을 확인한다.
4. 각 Claim의 암묵적 가정과 반증조건을 본다.
5. 방향조정 주가성과와 논지의 정합성을 확인한다.
6. 실제 사업/이벤트 데이터 검증이 필요한 사례는 검증 우선순위 큐에서 관리한다.

## 향후 정밀 검증 필드
- 실제 Catalyst 발생 여부와 날짜
- Thesis horizon 시점의 사업 결과
- 최초 공개 반증 신호와 날짜
- 2026년 현재 사업 상태
- 최종 성공/실패 메커니즘
- 외부 출처와 검증 수준
