# 성공·실패 패턴 허브 V2

## 핵심 탐색 흐름

1. 성공 패턴 / 실패 패턴 선택
2. 패턴 카드 선택
3. 해당 패턴 후보 기업·VIC 아이디어 확인
4. 아이디어 행 선택
5. `기업·아이디어 분석`으로 이동
6. 사업 / 핵심논지 / Catalyst / 밸류에이션 / 주가 / 현재를 분리해 검증
7. 실패 해부와 반증 질문으로 연결

## 자동 후보와 정밀 검증의 차이

현재 V2의 패턴 카운트는 VIC 당시 본문에서 추출한 자동 서사 태그와 방향조정 주가성과를 결합한 탐색용 후보이다.

- 우선 성과 기간: 3년
- 3년 데이터가 없으면 1년, 이후 5년
- +10% 이상: 성공 패턴 자동 후보에 매핑 가능
- -10% 이하: 실패 패턴 자동 후보에 매핑 가능
- 이 결과는 **원래 투자논지가 맞았다는 인과판정이 아니다.**

정밀 검증이 완료되면 `analysis.overall_verdict_ko`, `claims.outcome_ko`, `idea_pattern_map.thesis_verdict_ko`를 통해 자동 후보와 실제 논지 판정을 분리한다.

## 성공 패턴 8개

- 저평가 + 촉매 현실화
- 자본배분 개선
- 실적 정상화 + 밸류에이션 회복
- 사이클 저점 + 공급규율
- 산업 통합 + 경쟁강도 완화
- 반복매출 + 가격결정력
- 구조적 성장의 실제 실현
- 구조적 악화의 선행 포착(숏)

## 실패 패턴 15개

- 시장규모(TAM) 과대추정
- 네트워크 효과 과대평가
- 가격결정력 과대평가
- 영업레버리지 과대평가
- 경영진 내러티브 의존
- 공급 반응 무시
- M&A·롤업 경제성 오판
- 촉매 미실현·지연
- 싼 가격을 가치로 착각
- 가치사슬 협상력 이동
- 회계이익과 현금경제성 혼동
- 레버리지와 유동성 과소평가
- 저원가 우위를 구조적 해자로 오인
- 구조적 성장과 일시적 성장 혼동
- 시간축·촉매 지연 위험

## 최종적으로 채울 정밀 필드

- 회사 설명 / 사업모델 / 산업구조
- 당시 투자논지와 핵심 Claim
- 당시 근거 / 암묵적 가정
- Falsifier / leading indicator
- Thesis horizon 결과
- Event/Catalyst 결과
- 현재 상태
- 실패 메커니즘
- 근본 분석 오류
- 최초 반증 신호와 날짜
- 당시 알 수 있었는지 / 피할 수 있었는지
- 당시 물었어야 할 반증 질문
